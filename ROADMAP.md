- [x] Persistent vector memory (ChromaDB + ONNX)
- [x] Documents editor with AI assist
- [x] Autonomous agent with tools (web, file, shell, memory)
- [x] Deep research pipeline
- [x] Blind model comparison
- [x] Hardware-aware Cookbook (model manager)
